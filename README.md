
# Customer Churn Prediction

## Project Overview

This project focuses on predicting customer churn for a telecommunications company using machine learning. The goal is to identify customers who are likely to leave the service and provide insights that can support customer retention strategies.

The project includes exploratory data analysis, statistical analysis, machine learning model comparison, and an interactive Streamlit application for churn prediction.

## Business Objective

Customer churn can lead to revenue loss and increased customer acquisition costs.

The main objectives are to:

- Identify factors associated with customer churn.
- Build a machine learning model to predict potential churn.
- Evaluate and compare different classification models.
- Provide actionable business insights to support customer retention.

## Dataset

The project uses the Telco Customer Churn dataset.

- **Total customers:** 7,043
- **Original features:** 21 columns
- **Target variable:** `Churn`
- **Churned customers:** 1,869
- **Retained customers:** 5,174

The dataset contains customer demographics, account information, subscribed services, contract details, and billing information.

## Machine Learning Approach

The project follows these steps:

1. Data cleaning and preprocessing.
2. Exploratory Data Analysis (EDA).
3. Statistical analysis using Chi-square and Mann–Whitney U tests.
4. Feature engineering.
5. Train-test split.
6. Model training and comparison.
7. Hyperparameter tuning.
8. Model evaluation and interpretation.

### Models Evaluated

- Logistic Regression
- Random Forest
- Tuned Random Forest
- Logistic Regression with Feature Engineering

### Selected Model

Logistic Regression was selected based on the overall evaluation results and its balance between predictive performance and interpretability.

## Model Performance

**Selected model: Logistic Regression**

| Metric | Score |
|---|---:|
| Accuracy | 80.55% |
| Precision | 65.72% |
| Recall | 55.88% |
| F1-score | 60.40% |
| ROC-AUC | 84.20% |

The model achieved a ROC-AUC score of 0.8420, indicating good ability to distinguish between customers who churn and those who stay.

## Interactive Streamlit Application

The project includes an interactive web application with two main sections:

**1. Churn Prediction**
- Enter customer information.
- Predict the likelihood of customer churn.
- View churn probability and risk level.

**2. Customer Analytics**
- Explore historical churn patterns.
- Analyze churn by contract type, tenure, internet service, and monthly charges.
- View key business insights through interactive charts.
